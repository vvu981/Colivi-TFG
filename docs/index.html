1. Arquitectura y Stack Tecnologico

El sistema opera bajo una arquitectura distribuida y desacoplada de 5 servicios totalmente integrados mediante Docker:

Frontend
Vite + React 19

SPA con TypeScript, Tailwind CSS, TanStack Query y componentes interactivos.

Backend REST
Java 21 + Spring Boot 3

Arquitectura por capas, seguridad JWT, Flyway y validacion estricta de dominio.

Persistencia
PostgreSQL 16

Base de datos relacional con soporte nativo JSONB para auditoria inmutable.

Inteligencia Artificial
Servidor MCP (Node.js)

Model Context Protocol para auditoria conversacional y orquestacion con LLM.

Mensajeria Local
Mailpit (SMTP Mock)

Servidor de correo local para captura de enlaces de activacion y avisos.

2. Requisitos Previos Minimos

Para evitar configurar entornos JDK, Maven o Node en la maquina anfitriona, la ejecucion se ha abstraido integramente. Solo se requiere:

  • Docker Desktop (en ejecucion, con soporte Docker Compose v2).
  • Git (para clonar el repositorio).

6. Flujo de Evaluacion para el Tutor

Se sugieren los siguientes recorridos para contrastar la implementacion con los objetivos tecnicos del TFG:

Flujo 1: Marketplace de Alojamiento y Anuncios

1. Ingrese a http://localhost:5173 sin iniciar sesion (rol Invitado).

2. Explore el catalogo publico de anuncios comerciales con filtros interactivos.

3. Inicie sesion con victor@colivi.com para verificar las opciones de moderacion y creacion de inmuebles con multiples imagenes.

Flujo 2: Modulo de Hogar y Motor de Gastos Compartidos

1. Inicie sesion con ana@colivi.com o carlos@colivi.com.

2. Acceda a la seccion del hogar Piso Estudiantes Centro (codigo de invitacion: PISO-CENTRO-2024).

3. Observe la seccion de Gastos y Deudas: el algoritmo de simplificacion calcula en memoria el grafo optimo de pagos sin alterar los registros historicos.

4. Registre un nuevo gasto compartido indicando importe y miembros afectados para verificar la actualizacion en tiempo real de los balances.

Flujo 3: Notificaciones y Correos con Mailpit

1. Si ejecuta alguna accion que dispare emails transaccionales (por ejemplo, registro de nuevo usuario o reactivacion).

2. Abra http://localhost:8025 para visualizar el servidor SMTP local de Mailpit, donde los correos quedan capturados sin necesidad de conexion a servicios de terceros.

7. Resolucion de Incidencias Comunes

Conflicto de Puertos (5432 o 8080 en uso)

Si la maquina anfitriona ya cuenta con una instancia local de PostgreSQL o Spring Boot ejecutandose en los puertos 5432 o 8080, detenga temporalmente dichos servicios locales o edite el mapeo en el archivo docker-compose.yml (por ejemplo, cambiar "5432:5432" por "5433:5432").

Reinicio limpio del entorno

Para reiniciar el entorno restableciendo la base de datos a su estado original sembrado:

Terminal 
docker compose down -v
docker compose up -d

8. Detencion del Sistema

Para detener la ejecucion y liberar los recursos del sistema al concluir la sesion de evaluacion:

Terminal 
docker compose down
