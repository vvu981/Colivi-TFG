    Colivi nace como una plataforma web dirigida a solventar las trabas habituales al buscar piso compartido y organizar el día a día entre estudiantes. Se resolvieron dos problemas tradicionalmente desconectados: la captación de habitaciones y la convivencia interna.

    El sistema se apoya en un backend desarrollado con Java 21 sobre Spring Boot 3 y persistencia en PostgreSQL, enlazado con un cliente web interactivo en React. A esta base técnica se añade un microservicio independiente en Node.js que implementa el protocolo MCP (\emph{Model Context Protocol}). Gracias a esta pieza, el modelo de lenguaje consulta anuncios disponibles, inspecciona los turnos de limpieza pendientes y extrae resúmenes de la mensajería interna sin mutar datos en el servidor.

    Las decisiones de diseño priorizan el desacoplamiento mediante principios SOLID y patrones de diseño guiado por el dominio (DDD). Se abordaron retos técnicos exigentes: la concurrencia en la reserva de habitaciones mediante bloqueos en base de datos, el cálculo determinista de balances contables entre compañeros y la gamificación en el reparto de tareas domésticas.

%\section*{Abstract}
    Colivi addresses the recurrent friction students face when searching for shared flats and organizing daily life with roommates. Finding rooms from abroad during exchange programs usually means dealing with fragmented listings and unverified landlords. Once settled, chores and shared expenses trigger avoidable tensions.

    The architecture combines a Java 21 backend built on Spring Boot 3 with a PostgreSQL relational database and an interactive React web frontend. An external Node.js microservice exposes tools through the Model Context Protocol (MCP), enabling an LLM agent to inspect household chore rotations, query housing listings, and summarize inbox notifications safely under read-only boundaries.

    Engineering decisions focused on SOLID principles and Domain-Driven Design (DDD). The implementation tackles strict database-level concurrency controls during booking transitions, graph-based debt balance resolutions between tenants, and a fair round-robin task assignment engine.
