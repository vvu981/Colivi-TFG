\chapter{Análisis funcional}
\label{Análisis funcional}

    El análisis funcional traduce las dinámicas del coliving en especificaciones de ingeniería rigurosas, delimitando la frontera del sistema antes de entrar en la codificación. Se modelan los contratos de interacción, las entidades de datos y las restricciones de seguridad que rigen la plataforma Colivi.

    Los usuarios se clasifican según sus privilegios y su grado de participación en la convivencia, distinguiendo desde visitantes anónimos hasta administradores de plataforma. Los diagramas de casos de uso estructuran visualmente los flujos entre el navegador web y las APIs del servidor, agrupando las funcionalidades en paquetes de dominio.

    La especificación técnica se completa con el catálogo formal de requisitos funcionales y no funcionales, fijando las restricciones de latencia, seguridad sin estado mediante JWT y transacciones ACID en PostgreSQL. Sobre esta base analítica se asientan el modelo relacional y las pantallas diseñadas en Figma para guiar la maquetación.
