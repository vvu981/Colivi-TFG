\subsection{Descripción de los requisitos funcionales}

\begin{description}
    \item[RF-01.] El sistema permitirá crear una cuenta mediante correo electrónico y contraseña.

    \item[RF-02.] El sistema permitirá iniciar sesión utilizando las credenciales registradas.

    \item[RF-03.] El sistema permitirá autenticarse mediante una cuenta de Google.

    \item[RF-04.] El sistema permitirá renovar el token de acceso para mantener la sesión activa.

    \item[RF-05.] El sistema permitirá cerrar la sesión del usuario autenticado.

    \item[RF-06.] El sistema permitirá solicitar la recuperación de una contraseña olvidada.

    \item[RF-07.] El sistema permitirá establecer una nueva contraseña mediante un token seguro.

    \item[RF-08.] El sistema permitirá solicitar la reactivación de una cuenta.

    \item[RF-09.] El sistema permitirá confirmar la reactivación de una cuenta mediante un token.

    \item[RF-10.] El sistema permitirá consultar la información del perfil propio.

    \item[RF-11.] El sistema permitirá modificar la información personal no sensible del usuario.

    \item[RF-12.] El sistema permitirá modificar las credenciales y el correo electrónico del usuario.

    \item[RF-13.] El sistema permitirá subir y actualizar la imagen de perfil.

    \item[RF-14.] El sistema permitirá consultar los perfiles públicos de otros usuarios.

    \item[RF-15.] El sistema permitirá solicitar la baja de una cuenta mediante borrado lógico.

    \item[RF-16.] El sistema permitirá buscar anuncios aplicando diferentes filtros de búsqueda.

    \item[RF-17.] El sistema permitirá explorar los anuncios disponibles mediante un mapa interactivo.

    \item[RF-18.] El sistema permitirá consultar la información detallada de un anuncio y sus habitaciones asociadas.

    \item[RF-19.] El sistema permitirá a los anfitriones registrar nuevos inmuebles.

    \item[RF-20.] El sistema permitirá modificar la información de los inmuebles registrados.

    \item[RF-21.] El sistema permitirá subir fotografías de los inmuebles a un servicio externo de almacenamiento.

    \item[RF-22.] El sistema permitirá geolocalizar las direcciones de los inmuebles en un mapa.

    \item[RF-23.] El sistema permitirá publicar anuncios de habitaciones o pisos completos.

    \item[RF-24.] El sistema permitirá actualizar los precios, depósitos y condiciones de los anuncios.

    \item[RF-25.] El sistema permitirá seleccionar y establecer el orden de las fotografías de un anuncio.

    \item[RF-26.] El sistema permitirá modificar la visibilidad de los anuncios entre disponible y pausado.

    \item[RF-27.] El sistema permitirá consultar el historial de búsquedas recientes del usuario.

    \item[RF-28.] El sistema permitirá generar recomendaciones de anuncios personalizadas a partir del historial de búsquedas.

    \item[RF-29.] El sistema permitirá consultar las reseñas y la puntuación media de los usuarios.

    \item[RF-30.] El sistema comprobará si un usuario cumple las condiciones necesarias para publicar una reseña.

    \item[RF-31.] El sistema permitirá publicar reseñas y calificaciones sobre las estancias.

    \item[RF-32.] El sistema permitirá enviar solicitudes de reserva indicando un rango de fechas.

    \item[RF-33.] El sistema permitirá a los inquilinos consultar el historial de sus solicitudes de reserva.

    \item[RF-34.] El sistema permitirá cancelar las solicitudes de reserva pendientes.

    \item[RF-35.] El sistema permitirá a los anfitriones consultar las solicitudes de reserva recibidas.

    \item[RF-36.] El sistema permitirá a los anfitriones aceptar solicitudes de reserva.

    \item[RF-37.] El sistema permitirá a los anfitriones rechazar solicitudes de reserva.

    \item[RF-38.] El sistema permitirá confirmar y registrar el pago de la fianza de una reserva aceptada.

    \item[RF-39.] El sistema permitirá crear espacios de convivencia para gestionar un hogar compartido.

    \item[RF-40.] El sistema permitirá consultar el panel y los detalles de un espacio de convivencia.

    \item[RF-41.] El sistema permitirá generar y regenerar códigos de invitación para un hogar.

    \item[RF-42.] El sistema permitirá incorporarse a un hogar mediante un código de invitación.

    \item[RF-43.] El sistema permitirá personalizar el color identificativo de cada miembro del hogar.

    \item[RF-44.] El sistema permitirá consultar el registro cronológico de actividad del hogar.

    \item[RF-45.] El sistema permitirá transferir los privilegios de administración del hogar a otro miembro.

    \item[RF-46.] El sistema permitirá al administrador expulsar miembros del hogar.

    \item[RF-47.] El sistema permitirá a los miembros abandonar un espacio de convivencia.

    \item[RF-48.] El sistema permitirá archivar y desarchivar la vista de un hogar.

    \item[RF-49.] El sistema permitirá consultar el historial de hogares anteriores.

    \item[RF-50.] El sistema permitirá registrar gastos compartidos y establecer su reparto entre los miembros.

    \item[RF-51.] El sistema permitirá modificar los detalles y el reparto de los gastos registrados.

    \item[RF-52.] El sistema permitirá eliminar gastos del registro del hogar.

    \item[RF-53.] El sistema permitirá filtrar los gastos según fechas y participantes.

    \item[RF-54.] El sistema permitirá consultar los balances económicos y las transferencias sugeridas entre miembros.

    \item[RF-55.] El sistema permitirá registrar liquidaciones y pagos directos entre miembros.

    \item[RF-56.] El sistema comprobará que el saldo de un miembro sea cero antes de permitir su salida o expulsión del hogar.

    \item[RF-57.] El sistema permitirá crear tareas individuales o series de tareas recurrentes.

    \item[RF-58.] El sistema permitirá configurar estrategias de asignación fija o rotativa para las tareas.

    \item[RF-59.] El sistema permitirá visualizar las tareas del hogar mediante un calendario y un cuadrante.

    \item[RF-60.] El sistema permitirá a los miembros completar las tareas que tengan asignadas.

    \item[RF-61.] El sistema permitirá asumir tareas vencidas que hayan sido asignadas a otros miembros.

    \item[RF-62.] El sistema permitirá eliminar tareas individuales o series recurrentes.

    \item[RF-63.] El sistema redistribuirá las tareas pendientes cuando un miembro abandone o sea expulsado del hogar.

    \item[RF-64.] El sistema permitirá iniciar conversaciones vinculadas a anuncios publicados.

    \item[RF-65.] El sistema permitirá consultar la bandeja de entrada y los mensajes no leídos.

    \item[RF-66.] El sistema permitirá consultar el historial de mensajes de una conversación.

    \item[RF-67.] El sistema permitirá enviar mensajes de texto a otros usuarios.

    \item[RF-68.] El sistema permitirá marcar las conversaciones como leídas.

    \item[RF-69.] El sistema permitirá interactuar con un asistente inteligente mediante lenguaje natural.

    \item[RF-70.] El sistema generará un ticket temporal de autenticación para autorizar el acceso del asistente a las herramientas disponibles.

    \item[RF-71.] El asistente permitirá realizar búsquedas semánticas de alojamientos según las preferencias del usuario.

    \item[RF-72.] El asistente permitirá consultar el estado de las reservas.

    \item[RF-73.] El asistente permitirá generar resúmenes inteligentes de los mensajes recibidos.

    \item[RF-74.] El asistente permitirá consultar el estado de las tareas del hogar.

    \item[RF-75.] El asistente permitirá inspeccionar la cola de moderación.

    \item[RF-76.] El sistema permitirá denunciar anuncios, usuarios y conversaciones.

    \item[RF-77.] El sistema permitirá al usuario denunciante consultar el resultado de la resolución de su denuncia.

    \item[RF-78.] El sistema permitirá a los administradores listar y filtrar las denuncias recibidas.

    \item[RF-79.] El sistema permitirá a los administradores consultar el historial de las conversaciones denunciadas.

    \item[RF-80.] El sistema permitirá a los administradores resolver denuncias individuales mediante un veredicto.

    \item[RF-81.] El sistema permitirá a los administradores procesar varias denuncias de forma conjunta.

    \item[RF-82.] El sistema permitirá consultar un ranking de los elementos que acumulan un mayor número de denuncias.

    \item[RF-83.] El sistema permitirá a los administradores listar los usuarios registrados aplicando diferentes filtros.

    \item[RF-84.] El sistema permitirá suspender o bloquear cuentas de usuarios.

    \item[RF-85.] El sistema permitirá a los administradores consultar el catálogo global de anuncios.

    \item[RF-86.] El sistema permitirá bloquear o retirar de publicación anuncios que infrinjan las normas de la plataforma.
\end{description}
